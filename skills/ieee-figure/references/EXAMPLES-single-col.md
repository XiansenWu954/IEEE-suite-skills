## Compliant one-column pattern

- Use width `88.9mm` / `3.5in`.
- Prefer a single main axis or a small two-panel vertical stack.
- Keep axis labels, ticks, and legends at 8pt or larger, with 9-10pt preferred.
- Use vector PDF for line plots, mathematical diagrams, and network schematics.
- Use direct labels or line styles so grayscale printing remains interpretable.
- Start captions with `Fig. N.` and cite references numerically as `[N]` when needed.
