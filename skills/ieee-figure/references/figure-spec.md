# IEEE Figure Spec

Verified: 2026-05-27

Sources:

- IEEE Graphics File Formatting: https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-graphics-for-your-article/file-formatting/

## Numeric requirements

| Check | IEEE-ready value |
|---|---|
| Single-column width | 88.9mm / 3.5in / 21 picas |
| Double-column width | 182mm / 7.16in / 43 picas |
| Maximum listed graphics size | 182mm x 220mm / 7.16in x 8.8in |
| Color or grayscale raster | >=300 DPI at final size |
| Black-and-white line art | >=600 DPI at final size |
| Minimum visible font size | >=8pt |
| Recommended visible font size | 9-10pt at final size |
| Preferred line-art output | Vector PDF, EPS, or PS |
| Accepted graphics formats | PS, EPS, PDF, PNG, or TIFF |

## Validation notes

- Measure dimensions at final publication size, not at a viewer's zoom level.
- Treat vector PDF as preferred for line plots, diagrams, charts, and text-heavy graphics.
- Use TIFF or PNG for true raster images such as photographs or heatmap rasters.
- Do not place raster plot screenshots into PDF wrappers because the PDF wrapper does not improve DPI.
- Embed fonts in PDF, EPS, and PS output or convert text to outlines only when the author accepts the loss of editable text.
- Keep typefaces consistent across all figures in a manuscript.
