# Non-IEEE Style Patterns To Rewrite

These examples are authored for this repository. They are not copied from any publisher guide.

## Citation Surface

- Avoid: `Prior work by Chen, 2024 shows the trend.`
- Use: `Prior work shows the trend [N].`
- Reason: IEEE manuscript flow relies on numbered citations assigned by first appearance.

## Figure Callouts

- Avoid: `Figure 3 demonstrates the architecture.`
- Use: `Fig. 3 shows the architecture.`
- Reason: IEEE running text abbreviates figure citations.

## Unsupported Flourish

- Avoid: `This breathtaking result proves our method is revolutionary.`
- Use: `The result indicates that the proposed method reduces latency on the supplied traces.`
- Reason: IEEE style favors specific evidence over promotional language.

## Abbreviation Drift

- Avoid: `deep neural network (DNN)` in one section and `neural network model (NNM)` for the same object later.
- Use: define one term once, then reuse it consistently.

## Unit Spacing

- Avoid: `5ms`, `10GHz`, and `3 d B`.
- Use: `5 ms`, `10 GHz`, and `3 dB`.
