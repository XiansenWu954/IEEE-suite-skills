# Red-Flag Phrases for IEEE Reviewer Replies

Avoid these phrasings because they can read as defensive, evasive, or condescending.

1. "This concern is baseless."
2. "The comment misses the point."
3. "As should be obvious..."
4. "We already explained this clearly."
5. "The reviewer failed to notice..."
6. "This is outside the reviewer's expertise."
7. "No change is necessary."
8. "We refuse to add this experiment."
9. "The requested analysis is impossible."
10. "This criticism is unfair."
11. "The reviewer overlooked our contribution."
12. "Everyone in the field knows this."
13. "The paper is already clear."
14. "We cannot be expected to do that."
15. "This issue is irrelevant."

Use a replacement pattern instead:

`We thank Reviewer N for raising this point. We have [made change / clarified scope / provided evidence / identified author input needed] in [location].`
