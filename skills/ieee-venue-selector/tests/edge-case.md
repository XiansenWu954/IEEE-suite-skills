## Input

My manuscript is 24 IEEE double-column pages on distributed graph databases. I only want an IEEE conference.

## Expected output

The skill filters conference rows by page limit and reports no conference fit if all matrix conference page budgets are exceeded.

```markdown
# Hard Filters

- Page count: 24 pages.
- All matrix conferences fail page-budget constraints.

# Result

No IEEE conference in the current matrix fits this manuscript without major shortening. Use `ieee-writing` to reduce the paper or reconsider journal venues.
```

## Pass criteria

- Does not recommend a too-short conference anyway.
- Does not invent a conference outside the matrix.
- Provides a concrete next step.
