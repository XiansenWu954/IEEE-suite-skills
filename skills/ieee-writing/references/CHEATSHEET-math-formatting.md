# IEEE Math And Unit Formatting Cheatsheet

Source basis: IEEE Editorial Style Manual for Authors, March 2025 revision, paraphrased for this skill.

## Variables, Functions, And Operators

- Set scalar variables, unknowns, and indices in italic math style.
- Keep standard operators and function names in roman style, including `sin`, `cos`, `log`, `lim`, `max`, `min`, `arg max`, `Pr`, and `E`.
- Use bold or vector notation consistently when the manuscript distinguishes vectors, matrices, and tensors.
- Do not mix prose symbols and equation symbols; define each symbol before repeated use.

## Equations

- Number displayed equations consecutively and refer to them as `(1)`, `(2)`, and so on.
- Put punctuation after displayed equations when the equation completes a sentence.
- Align multi-line derivations for readability, but do not renumber intermediate lines unless each line is cited.
- Mark any missing derivation or undefined variable as `AUTHOR_INPUT_NEEDED`.

## Units And Ranges

- Use SI units unless the field has a verified IEEE convention for another unit.
- Put a space between a numeral and unit symbol, such as `10 ms`, `5 GHz`, and `3 dB`.
- Repeat the unit only where needed for clarity in ranges, such as `5-10 ms` or `5 ms to 10 ms`, following the local venue's production preference.
- Keep unit symbols upright, not italic, and avoid pluralizing symbols.

## Figures, Tables, And Text

- Cite figures in text as `Fig. 1`, including when the citation starts a sentence.
- Cite tables as `Table I`, `Table II`, and so on when using IEEE roman-numeral table labels.
- Ensure first figure and table citations appear in numerical order.
- Keep displayed math, tables, and algorithms out of the abstract.
